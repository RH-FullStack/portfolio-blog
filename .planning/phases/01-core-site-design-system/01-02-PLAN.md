<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| site → external social targets | Footer GitHub/LinkedIn links open external sites in new tabs |
| keyboard/AT user → mobile overlay | Focus management is a security-adjacent accessibility control (focus must not escape to background) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | Footer external social links (reverse tabnabbing) | mitigate | Every `target="_blank"` social anchor in `Footer.tsx` carries `rel="noopener noreferrer"`; where feasible route through the `Button` primitive that bakes this in. |
| T-02-02 | Information Disclosure | Focus trap escaping mobile overlay to hidden background content | mitigate | Use Radix `Dialog` (not hand-rolled) so focus is trapped and returned correctly — background is `aria-hidden`/inert while open. |
| T-02-03 | Spoofing | `mailto:` link from `siteConfig.social.email` | accept | Address is a static developer-authored config string, not user input; no injection surface. |
</threat_model>
