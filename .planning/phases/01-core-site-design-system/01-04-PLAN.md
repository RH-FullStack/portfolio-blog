## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | Contact external social links (reverse tabnabbing) | mitigate | Every `target="_blank"` social anchor carries `rel="noopener noreferrer"`. |
| T-04-02 | Injection | `mailto:` built from `siteConfig.social.email` | accept | Address is a static developer-authored config string (not user input); no header-injection surface since there is no server-side mail handling. |
| T-04-03 | Injection | About/Contact/404 content rendering | accept | All copy is static typed TSX rendered as text; no `dangerouslySetInnerHTML`, no MDX in Phase 1. |
</threat_model>
