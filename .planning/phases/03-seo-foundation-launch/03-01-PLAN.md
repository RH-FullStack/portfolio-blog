```typescript
export async function generateMetadata({
  params,
}: {
  params: Promise<{ slug: string }>;
}): Promise<Metadata> {
  const { slug } = await params;
  const post = getPostBySlug(slug);
  if (!post) return {}; // page body's notFound() still handles the 404
  return {
    title: post.title,
    description: post.excerpt,
    alternates: { canonical: `/blog/${post.slug}` },
  };
}
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| build-time content → rendered `<meta>` tags | Velite frontmatter + hand-authored strings become page metadata |
| URL param (`slug`, `tag`) → generateMetadata lookup | Route params reach a data lookup (already constrained by `dynamicParams = false`) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Information Disclosure | `blog/[slug]` generateMetadata | mitigate | Call `getPostBySlug` (routes through `getPublishedPosts()` draft filter); never import raw Velite `posts` — a draft post must never surface a title/excerpt in metadata |
| T-03-02 | Tampering / XSS | all metadata sources | accept | Every source (Velite frontmatter, hand-authored strings) is developer-controlled, not end-user input; Next.js escapes metadata into `<meta>` attributes. No user input reflected |
| T-03-03 | Information Disclosure | canonical / OG URLs | mitigate | `alternates.canonical` uses a root-relative path resolved against `metadataBase` (NEXT_PUBLIC_SITE_URL) — no hardcoded domain, correct on any vercel.app subdomain (D-09) |
</threat_model>
