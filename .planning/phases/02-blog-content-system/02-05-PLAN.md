<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client URL (`/blog/[slug]`, `/blog/tags/[tag]`) → static route | The slug/tag path segment is untrusted client input crossing into route resolution |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-10 | Tampering / DoS | Arbitrary `[tag]` / `[slug]` in the URL | mitigate | `dynamicParams = false` + `generateStaticParams` restricted to the real published tag/slug set means any unknown value 404s at the CDN edge — no server-side rendering/computation for arbitrary input (ASVS V5). No dynamic fallback branch added. |
| T-02-11 | Information Disclosure | Draft post reachable via direct `/blog/[slug]` URL | mitigate | `generateStaticParams` maps `getAllPosts()` (draft-filtered in the single `getPublishedPosts()` accessor), so no static path exists for a draft; `dynamicParams=false` prevents on-demand rendering; `getPostBySlug` also excludes drafts (defense in depth, D-11). |
| T-02-12 | Elevation of Privilege | MDX executed via MDXContent's `new Function()` | accept | First-party git-committed content only (PROJECT.md: no CMS). Not a runtime user-input vector. |
</threat_model>
